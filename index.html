1. Проблема защиты информации

ИТКС объединяет каналы связи, серверы, конечные устройства и программное обеспечение. Защита информации обеспечивает конфиденциальность, целостность и доступность данных, а также контролирует несанкционированный доступ.

Модель разграничения доступа

USERS = {
    'admin': {'role': 'administrator', 'clearance': 3},
    'analyst': {'role': 'analyst', 'clearance': 2},
    'guest': {'role': 'guest', 'clearance': 1}
}

RESOURCES = {
    'public_report': 1,
    'financial_data': 2,
    'system_configuration': 3
}

def check_access(user, resource):
    if user not in USERS:
        return 'DENY: неизвестный пользователь'
    return 'ALLOW' if USERS[user]['clearance'] >= RESOURCES[resource] else 'DENY'

print(check_access('analyst', 'financial_data'))          # ALLOW
print(check_access('guest', 'system_configuration'))       # DENY

Вывод: формальная матрица доступа позволяет реализовать принцип наименьших привилегий. Дополнительные материалы: OWASP Cheat Sheet Series, Kaggle: cybersecurity, Хабр: ИБ.

2. Уязвимость линий передачи

Каналы связи подвержены перехвату, модификации, подмене отправителя и атакам на доступность. Хеш-функция SHA-256 позволяет обнаружить изменение сообщения.

import hashlib

def digest(data: str) -> str:
    return hashlib.sha256(data.encode('utf-8')).hexdigest()

original = 'Сумма перевода: 50 000 руб.'
modified = 'Сумма перевода: 5 000 руб.'

print(digest(original))
print(digest(modified))
print('Целостность нарушена:', digest(original) != digest(modified))

Вывод: хеш выявляет подмену данных, но не подтверждает авторство. Для этого применяются MAC или электронная подпись. Стандарт: NIST FIPS 180-4.

3. Компьютерные преступления и инциденты

В РФ компьютерные преступления регулируются статьями 272–274.1 УК РФ: неправомерный доступ, вредоносные программы, нарушение правил эксплуатации и воздействие на критическую инфраструктуру. Расследование требует фиксации журналов, сетевого трафика, метаданных и образов носителей.

def triage(event_type):
    rules = {
        'brute_force': 'Проверить журналы аутентификации, заблокировать IP',
        'malware': 'Изолировать хост, снять образ памяти и диска',
        'phishing': 'Заблокировать ссылку, уведомить пользователей',
        'data_exfiltration': 'Ограничить исходящий трафик, провести форензику'
    }
    return rules.get(event_type, 'Провести стандартное расследование')

print(triage('malware'))

Предпосылки инцидентов: слабые пароли, ошибки конфигурации, отсутствие обновлений, фишинг, инсайдеры и избыточные права доступа. Ресурсы: MITRE ATT&CK, The DFIR Report.

4. Межсетевой экран

Межсетевой экран фильтрует трафик по адресам, портам, протоколам и правилам политики безопасности. Рекомендуемый подход — «запрещено всё, что явно не разрешено».

class SimpleFirewall:
    def __init__(self):
        self.rules, self.log = [], []

    def add_rule(self, action, src, port, protocol):
        self.rules.append((action, src, port, protocol))

    def inspect(self, src, port, protocol):
        for action, rule_src, rule_port, rule_proto in self.rules:
            if rule_src == 'any' and rule_port == port and rule_proto == protocol:
                self.log.append((src, port, protocol, action.upper()))
                return action.upper()
        self.log.append((src, port, protocol, 'DENY'))
        return 'DENY'

fw = SimpleFirewall()
fw.add_rule('allow', 'any', 443, 'TCP')
fw.add_rule('deny', 'any', 23, 'TCP')

print(fw.inspect('203.0.113.10', 443, 'TCP'))  # ALLOW
print(fw.inspect('203.0.113.10', 23, 'TCP'))   # DENY

Вывод: МЭ уменьшает поверхность атаки, но не заменяет обновления, антивирус и контроль учетных записей. Примеры: pfSense, OPNsense.

5. Защита ПО и данных ПЭВМ

Защита строится по принципу эшелонированной обороны: контроль целостности, резервные копии, обновления, шифрование, журналирование и ограничение привилегий.

import hashlib

def file_hash(content: str) -> str:
    return hashlib.sha256(content.encode()).hexdigest()

baseline = file_hash('allow_remote_access=false')
current  = file_hash('allow_remote_access=true')

print('Целостность нарушена:', baseline != current)

Правило 3-2-1

Три копии данных, два разных носителя, одна копия вне площадки.

Наименьшие привилегии

Пользователь получает только необходимые права.

Контроль целостности

Хеши и цифровые подписи выявляют изменения файлов.

Рекомендации: CIS Controls, NIST CSF.

6. Криптография и электронная подпись

Симметричное шифрование использует один ключ и подходит для больших объемов данных. Асимметричное шифрование использует пару ключей и решает задачу защищенного обмена ключами. Электронная подпись обеспечивает целостность, аутентичность и неотказуемость.

from cryptography.fernet import Fernet

key = Fernet.generate_key()
cipher = Fernet(key)

message = 'Конфиденциальные данные: договор №45'
token = cipher.encrypt(message.encode())

print(cipher.decrypt(token).decode())
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
public_key = private_key.public_key()

document = b'Электронный договор №45'
signature = private_key.sign(
    document,
    padding.PSS(mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH),
    hashes.SHA256()
)

public_key.verify(
    signature, document,
    padding.PSS(mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH),
    hashes.SHA256()
)
print('Подпись действительна')

Вывод: на практике используется гибридная схема: RSA защищает сеансовый ключ, а симметричный алгоритм шифрует данные. Библиотека: pyca/cryptography.

7. Интернет, вирусы и антивирусы

Основные угрозы Интернета — фишинг, вредоносные вложения, эксплойты, шпионское ПО и программы-вымогатели. Антивирусные продукты используют сигнатуры, эвристику, поведенческий анализ, песочницу и облачную репутацию.

import re

PATTERNS = {
    'срочность': r'(срочно|немедленно|account suspended)',
    'запрос пароля': r'(введите пароль|password|credentials)',
    'сокращённая ссылка': r'(bit\.ly|tinyurl\.com)',
    'исполняемый файл': r'\.(exe|scr|bat|js|vbs)$'
}

def scan(text):
    findings = [k for k, p in PATTERNS.items() if re.search(p, text, re.I)]
    return 'Высокий риск' if len(findings) >= 2 else 'Средний риск' if findings else 'Низкий риск'

print(scan('Срочно введите пароль: http://bit.ly/login'))

Вывод: сигнатуры обнаруживают известные угрозы, а эвристика и поведение помогают выявлять новые. Ресурсы: VirusTotal, ClamAV, Kaggle: malware, Hugging Face.
